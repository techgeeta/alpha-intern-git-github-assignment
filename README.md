# Git & GitHub Workshop Assignment

## Introduction
**Git** is a distributed version control system that tracks changes in source code during software development. It allows multiple developers to work on the same project simultaneously without conflicts.

**GitHub** is a cloud-based hosting service for managing Git repositories. It provides a platform for collaboration, code review, and project management.
# Git and GitHub

Git is a distributed version control system used to track changes in source code and files.

GitHub is a cloud-based platform that hosts Git repositories and allows collaboration among developers.

## Features of Git
- Version Control
- Branching and Merging
- Commit History
- Collaboration

## Features of GitHub
- Remote Repository Hosting
- Pull Requests
- Collaboration
- Issue Tracking
