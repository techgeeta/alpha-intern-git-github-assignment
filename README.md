# Git & GitHub Workshop Assignment

## Introduction
**Git** is a distributed version control system that tracks changes in source code during software development. It allows multiple developers to work on the same project simultaneously without conflicts.

**GitHub** is a cloud-based hosting service for managing Git repositories. It provides a platform for collaboration, code review, and project management.

## Git vs GitHub
- Git is the tool that manages version control locally and across branches.
- GitHub is the online service used to host Git repositories and collaborate with others.

## Features of Git
- Version control for files and code
- Branching and merging support
- Commit history and rollback
- Collaboration with multiple developers

## Features of GitHub
- Remote repository hosting
- Pull requests and code review
- Issue tracking and project boards
- Team collaboration and sharing

1. Clone the repository using `git clone`.
2. Create a new branch for your work if needed.
3. Add or update files in the appropriate folder.
4. Commit changes with descriptive messages.
5. Push your branch to GitHub and create a pull request if required.
